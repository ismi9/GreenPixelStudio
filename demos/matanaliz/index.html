§4 · РОЗДІЛ ЧЕТВЕРТИЙ · ПРИКЛАДНІ ЗАДАЧІ

Практика зі страхівкою.

Задачі екзаменаційного типу з поступовими підказками та повністю розписаними розв'язками. Відповіді приймають десяткові та звичайні дроби — 0,3 і 3/10 однаково правильні.

01
ПОХІДНА · пов'язані швидкості

Драбина ковзає

Драбина завдовжки 5 м спирається на стіну. Її основа ковзає від стіни зі швидкістю 0,4 м/с. Наскільки швидко верхівка ковзає вниз по стіні в мить, коли основа відійшла на 3 м?
Використай теорему Піфагора: x² + y² = 25. Знайди y при x = 3.
Продиференціюй: 2x·dx/dt + 2y·dy/dt = 0. Підстав x=3, y=4, dx/dt=0.4.
y = √(25−9) = 4 м. 2(3)(0.4) + 2(4)(dy/dt) = 0 → 2.4 + 8(dy/dt) = 0 → dy/dt = −0.3 м/с. Відповідь: 0,3 м/с вниз.
02
ПОХІДНА · оптимізація

Паркання вздовж річки

Є 40 м паркана для прямокутного загону вздовж прямої ділянки річки — з боку річки паркант не потрібен. Яку найбільшу площу можна огородити?
Площа S = x·y, обмеження: 2x + y = 40 (три сторони).
Вирази y = 40 − 2x, тоді S = x(40−2x). Знайди максимум: dS/dx = 0.
S = 40x − 2x², dS/dx = 40 − 4x = 0 → x = 10, y = 20. S = 200 м².
03
ІНТЕГРАЛ · означений інтеграл

Площа під параболою

Обчисліть орієнтовану площу між f(x) = 4 − x² та віссю x від x = 0 до x = 2. (Ця крива живе у §2 — поставте там a=0,b=2 і спостерігайте, як Sₙ підбирається до вашої відповіді.)
∫₀² (4−x²) dx = [4x − x³/3]₀²
Підстав межі: (8 − 8/3) − (0) = 16/3.
∫₀² (4−x²)dx = [4x − x³/3]₀² = (8 − 8/3) − 0 = 16/3 ≈ 5,333 м².
04
ГРАНИЦЯ · границя ε–δ

Дірка на початку координат

Обчисліть lim(x→0) (√(x+4) − 2) / x — а потім захистіть відповідь: чому невизначеність 0/0 не заважає границі існувати?
Домнож на спряжений: (√(x+4)+2).
Чисельник: (x+4)−4 = x. Скороти x.
((√(x+4)−2)(√(x+4)+2)) / (x(√(x+4)+2)) = (x+4−4)/(x(√(x+4)+2)) = x/(x(√(x+4)+2)) = 1/(√(x+4)+2). При x→0: 1/(2+2) = 1/4.
