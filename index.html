🚀 Platform Specification 1.0

Платформа LifeStock — стандарт для управління запасами

Відкрита розширювана платформа: сканування штрихкодів, контроль термінів придатності, списки покупок, автоматизації. Ядро працює без інтернету та без AI.

Переглянути специфікацію Каталог модулів
🛡️

Ядро не залежить від ШІ

Усі критичні функції — облік, терміни придатності, рух товарів, звіти — працюють без підключення до моделей штучного інтелекту. ШІ — помічник, а не обов'язкова частина системи. Немає інтернету? Платформа продовжує працювати.

API версіонування

Сумісність при оновленнях

Кожен API має власну версію — оновлення платформи без порушення сумісності.

v1

API v1 — Стабільний

Базові CRUD-операції: товари, партії, запаси, списки покупок. Стабільний контракт, гарантована зворотна сумісність.

  • GET /api/v1/products
  • POST /api/v1/batches
  • GET /api/v1/inventory
  • POST /api/v1/shopping-list
v2

API v2 — Розширений

Партіонний облік, події, webhook, автоматизації. Розширена фільтрація, пагінація, real-time оновлення.

  • POST /api/v2/automations
  • GET /api/v2/events/stream
  • POST /api/v2/webhooks
  • GET /api/v2/reports/custom
v3

API v3 — Майбутнє

Командні простори, інтеграції ERP/POS, GraphQL-ендпоінти, multi-tenant архітектура.

  • GraphQL /api/v3/graphql
  • POST /api/v3/teams
  • POST /api/v3/erp/sync
  • GET /api/v3/analytics
AI-платформа

ШІ — окремий сервіс за дозволом користувача

AI працює лише за згодою. Без нього платформа функціонує повноцінно.

📸

Аналіз фото

Розпізнавання товарів за фотографією, підрахунок кількості на полиці.

🔤

OCR

Зчитування тексту з етикеток: склад, терміни, ціни — без ручного вводу.

🍳

Підбір рецептів

Рецепти на основі наявних залишків. "Що приготувати з того, що є?"

📊

Аналіз залишків

Виявлення надлишків, дефіциту, оптимізація розміщення товарів.

🔮

Прогнозування закупівель

Прогноз попиту на основі історії витрати, сезонності, подій.

💬

Запити до бази даних

"Скільки кави залишилось?" — відповіді природною мовою на основі власної бази.

🔒

ШІ активується тільки за добровільною згодою користувача. Усі дані обробляються локально, коли це можливо. Вимкнення AI не впливає на роботу платформи.

Конструктор автоматизацій

Правила без програмування

Користувачі створюють правила за схемою "Якщо → Тоді" — без коду.

Якщо

📉 Залишок < мінімального
⏳ Термін придатності ≤ 3 днів
🌡️ Температура в холодильнику вища за норму
